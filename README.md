# Botania Ponder

Client-side Ponder scenes for Botania on Minecraft Forge 1.20.1.

The mod adds visual, step-by-step explanations for Mana Pools, Mana Spreaders, crafting devices,
generating flowers, functional flowers, and other Botania mechanics. It is client-side only and does
not need to be installed on a server.

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- Botania 1.20.1-454 or newer
- PonderLib 0.5.0 or newer

## Installation

Install Botania, PonderLib, and Botania Ponder in the client `mods` directory. Open a supported
Botania item's Ponder entry using the configured Ponder key.

## Building

```shell
./gradlew build
```

The built mod is written to `build/libs`.
